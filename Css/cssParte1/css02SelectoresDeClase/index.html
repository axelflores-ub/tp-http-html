Selectores de clase

A partir de esta página dejamos de usar el atributo style en las etiquetas.

Todo el estilo del documento se define dentro de una etiqueta style anidada en el head, usando clases (.nombreClase).

p {
    font-size: 1em;
    margin-bottom: 40px;
}

Este es el estilo por default de cualquier párrafo: deja un margen inferior para separarlos entre sí.

.destacado {
    font-weight: bold;
    background-color: #fff3b0;
    padding: 10px;
}

Este párrafo toma el estilo definido en la etiqueta style como class="destacado".

.nota {
    font-size: 0.85em;
    font-style: italic;
    border: 1px solid #cfd8dc;
    background-color: #f5f7f8;
    padding: 10px;
}

Este párrafo usa la clase "nota": letra más chica, en cursiva y dentro de un recuadro, pensada para agregar aclaraciones secundarias sin robarle protagonismo al contenido principal.

.ayuda {
    font-style: italic;
    color: #ef6c00;
    border: 1px solid #ffcc80;
    background-color: #fff8f0;
    text-align: center;
    padding: 10px;
}

Este párrafo toma el estilo definido en la etiqueta style como class="ayuda".

Este párrafo tiene la clase "contenidoComun" aplicada, aunque para esa clase no se definió ningún estilo particular, por lo que se ve igual que un párrafo normal.

#soloUno {
    border: 2px solid #c62828;
    color: #c62828;
    font-weight: bold;
    text-align: center;
    padding: 10px;
    background-color: #fdecea;
}

Este párrafo tiene un estilo particular definido en el style del documento para un elemento específico con id="soloUno". No es un selector de clase sino un selector de elemento, por eso se usa "#" en lugar de ".".

.imagenMitad {
    width: 50%;
}
