Declaraciones en bloque definidas entre etiquetas style

h1 {
    text-align: center;
    font-size: 1.8em; /*Un poco menos del doble de lo definido para el contenedor padre*/
    color: #1d3557;
    background-color: #cfe0fc;
}

Todos los títulos con etiqueta h1 comparten este mismo estilo.

El h1 ocupa todo el ancho del contenedor (por default lleva display de bloque)

El texto del h1 se muestra en azul oscuro (#1d3557).

El fondo de cada h1 es celeste claro (#cfe0fc).

El estilo indica que el texto del h1 va centrado y con un tamaño de 1.8em.

p {
    text-align: right;
    font-size: 1.1em;
    color: #333333;
    background-color: #fdf3e7;
    font-style: italic;
    border-left-style: solid;
    border-right-style: solid;
    border-width: medium;
    border-color: #e76f51;
}

Todos los textos con etiqueta p tienen este estilo definido dentro de la etiqueta style.

Los párrafos quedan alineados a la derecha.

El tamaño de letra es de 1.1em, un poco mayor al definido para el contenedor body.

El color de letra es gris oscuro, para que se lea con buen contraste.

El fondo de cada párrafo es color crema claro (#fdf3e7).

El estilo de la fuente es itálica.

Los bordes izquierdo y derecho son sólidos, de grosor medio y color naranja.
