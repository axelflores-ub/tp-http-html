Tamaño de letra según la resolución de la pantalla

Los textos con etiqueta "h1" tienen el doble de tamaño que los párrafos comunes, así se distinguen como títulos.

En este ejercicio se define un tamaño de letra default para el body, y todo el resto se expresa en unidades "em" (que toman ese valor como referencia).

Para que el tamaño de letra cambie según el ancho de la pantalla, se usa la consulta de medios "@media()".

La resolución de una pantalla se mide en píxeles de ancho por píxeles de alto.

Los dispositivos chicos suelen tener mayor densidad de píxeles: por ejemplo, alrededor de 500ppp (píxeles por pulgada) en un celular moderno.

Los dispositivos con pantallas grandes suelen tener menor densidad, del orden de los 100ppp.

Por eso, el tamaño "visual" de las cosas termina siendo parecido tanto en pantallas grandes como chicas, aunque la cantidad de píxeles sea muy distinta.

Si un dispositivo tiene alta densidad de píxeles, el texto puede definirse con más píxeles sin verse gigante.

Por eso, si no se usa "@media", conviene definir el tamaño de letra pensando en el peor caso: los dispositivos de baja resolución.

En este ejercicio la letra crece a medida que el ancho de pantalla (viewport) es mayor:

12px (1em) para pantallas angostas, de baja resolución. No hay que olvidarse de definir este valor default en el body.

24px (2em) para pantallas de resolución media, entre 800px y 1080px de ancho.

36px (3em) para pantallas anchas, de alta resolución (más de 1080px).
