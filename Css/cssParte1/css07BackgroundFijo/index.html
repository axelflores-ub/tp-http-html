El padding es importante para que el texto no quede pegado al borde de la caja.

No hay que olvidarse de usar box-sizing:border-box, para que el ancho y el alto de la caja sean exactamente los definidos en width y height (incluyendo borde y padding).

Al usar background-attachment:fixed, la imagen de fondo queda fija: aunque el texto se desplace al scrollear dentro del contenedor, el fondo no se mueve.
